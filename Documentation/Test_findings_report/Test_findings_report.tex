\section{Introducción y Alcance del Reporte}

El presente documento constituye el \textbf{Reporte de Hallazgos de Pruebas de la Versión Final (v1.0.0)} del sistema \textbf{Yoliztli}, elaborado como producto de auditoría técnica tras la ejecución de las seis actividades normadas por el estándar internacional \textbf{ISO/IEC/IEEE 14764:2014} y la guía \textbf{SWEBOK v4.0}.

El objetivo principal de esta evaluación es validar cuantitativa y cualitativamente la calidad del software liberado en la versión \textbf{v1.0.0}, demostrando la erradicación total de los defectos de confiabilidad detectados en la fase diagnóstica inicial, el cumplimiento estricto de las reglas de codificación y la aprobación del 100\% de las pruebas funcionales de caja negra.

\subsection{Infraestructura y Entorno de Ejecución de Pruebas}
Las pruebas de homologación y auditoría final fueron ejecutadas en la siguiente plataforma tecnológica:
\begin{itemize}
    \item \textbf{Sistema Operativo del Servidor}: Fedora Linux 44 Workstation.
    \item \textbf{Entorno de Ejecución Backend}: PHP 8.2.18 / Laravel Framework 10.48.x.
    \item \textbf{Motor de Base de Datos}: PostgreSQL 15.4 / SQLite (Modo Testing).
    \item \textbf{Compilador de Assets Frontend}: Vite 5.0.x / Inertia.js 1.0.x con React 18.2.0.
    \item \textbf{Inspección Estática Continua}: SonarQube Community Edition v25.2.0.
    \item \textbf{Herramientas de Estandarización de Código}: `PHP-CS-Fixer` (Reglas PSR-12) y `ESLint 8.x`.
\end{itemize}

\subsection{Verificación de Solución de Fallas Críticas}
\begin{enumerate}
    \item \textbf{Falla CP007 (Filtros de Búsqueda)}: Resuelta mediante el \textbf{MR-004}. La consulta en Laravel Eloquent refactorizó la cláusula \texttt{where} condicional, permitiendo filtrar cuentos por categoría (Náhuatl, Maya, Zapoteco, Otomí) y rangos de edad sin bloqueos.
    \item \textbf{Falla CP008 (Persistencia en BD)}: Resuelta mediante el \textbf{MR-005}. Se crearon las migraciones y controladores necesarios para persistir las lecturas completadas y estrellas obtenidas en la base de datos, asegurando la actualización en tiempo real en la pantalla de Perfil.
\end{enumerate}

\section{Conclusiones y Dictamen de Liberación}

Tras auditar la versión \textbf{v1.0.0} del sistema \textbf{Yoliztli}, se concluye que:
\begin{enumerate}
    \item La aplicación aprobó exitosamente la inspección estática con \textbf{Quality Gate PASSED} y \textbf{Rating A} en SonarQube v25.2.0.
    \item La suite de pruebas de caja negra alcanzó un porcentaje de éxito del \textbf{100\% (8/8 pruebas aprobadas)}.
    \item Se solucionaron satisfactoriamente las incidencias críticas de compilación de frontend (\textbf{PR-001}), filtrado de contenidos (\textbf{CP007}) y persistencia de avance (\textbf{CP008}).
\end{enumerate}

En virtud de lo anterior, se otorga el \textbf{Dictamen de Aprobación Formal y Liberación de la Versión v1.0.0}.

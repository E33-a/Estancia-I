\section{Introducción y Arquitectura del Sistema}

El presente \textbf{Manual de Usuario Operacional} es la guía oficial de uso e interacción para la versión \textbf{v1.0.0} del sistema \textbf{Yoliztli} (Plataforma Educativa para la Enseñanza de Lenguas Originarias en Educación Primaria).

El sistema fue diseñado pensando en la inclusión digital, la sencillez de uso y la preservación cultural. Ofrece una navegación completamente intuitiva dividida en tres roles principales:
\begin{enumerate}
    \item \textbf{Rol Estudiante (Alumno)}: Diseñado con colores vibrantes e íconos interactivos. Permite a los niños leer cuentos en su lengua materna (Náhuatl, Maya, Zapoteco, Otomí), escuchar la pronunciación en audio, jugar minijuegos didácticos y consultar sus medallas de logro.
    \item \textbf{Rol Docente (Profesor)}: Diseñado para facilitar la labor del maestro. Permite dar seguimiento al avance de los niños en tiempo real, visualizar el progreso global del grupo y crear cuestionarios o evaluaciones personalizadas.
    \item \textbf{Rol Administrador}: Diseñado para la gestión técnica de la plataforma. Permite dar de alta y controlar usuarios, gestionar el catálogo de contenidos y configurar los parámetros del servidor.
\end{enumerate}

\section{Módulo I: Acceso, Autenticación e Identidad}

\subsection{Pantalla de Bienvenida y Selección de Idioma}
Al entrar al sistema por primera vez, se presenta la pantalla principal de bienvenida (Figura~\ref{fig:gui_welcome}). Desde esta interfaz, el usuario puede seleccionar la variante lingüística deseada antes de iniciar sesión.

\textbf{Pasos de uso recomendados:}
\begin{itemize}
    \item \textbf{Selección de Idioma}: Haga clic en uno de los botones disponibles (\textit{Español}, \textit{Náhuatl}, \textit{Maya}, \textit{Zapoteco} u \textit{Otomí}) para adaptar la interfaz.
    \item \textbf{Botones de Acceso}: Use el botón \textbf{"Iniciar Sesión"} si ya cuenta con un usuario, o \textbf{"Registrarse"} para crear una cuenta nueva.
\end{itemize}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.82\textwidth]{../img/Interfaces/Welcome__and__Language_Selection.png}
    \caption{Pantalla de Bienvenida y Selección de Idioma Originario.}
    \label{fig:gui_welcome}
\end{figure}

\newpage
\subsection{Inicio de Sesión (Login)}
La pantalla de autenticación (Figura~\ref{fig:gui_login}) permite a estudiantes, profesores y administradores ingresar de forma segura a sus portales correspondientes.

\textbf{Instrucciones para iniciar sesión:}
\begin{enumerate}
    \item Ingrese su dirección de \textbf{Correo Electrónico} registrada.
    \item Escriba su \textbf{Contraseña}.
    \item (Opcional) Marque la casilla \textbf{"Recordarme"} para mantener su sesión activa en el navegador.
    \item Haga clic en el botón \textbf{"Iniciar Sesión"}.
\end{enumerate}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.82\textwidth]{../img/Interfaces/Log_In.png}

\end{figure}

\section{Guía de Despliegue e Inicialización del Sistema (v1.0.0)}

Para desplegar e inicializar localmente la versión \textbf{v1.0.0} de Yoliztli en un servidor o máquina de desarrollo, ejecute los siguientes comandos en la terminal:

\begin{verbatim}
# 1. Acceder al directorio principal del proyecto
cd /ruta/al/proyecto/Estancia-I

# 2. Instalar dependencias backend (PHP) y frontend (Node.js)
composer install
npm install

# 3. Ejecutar migraciones de base de datos y sembrar datos iniciales
php artisan migrate --force
php artisan db:seed --force

# 4. Compilar los activos de producción de React con Vite
npm run build

# 5. Iniciar el servidor local de desarrollo
php artisan serve --port=8000
\end{verbatim}

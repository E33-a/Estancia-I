\part{Reporte de Hallazgos de Pruebas (Versión Final v1.0.0)}

\section{Introducción y Alcance del Reporte}

El presente documento constituye el \textbf{Reporte Final de Hallazgos de Pruebas y Manual de Usuario Operacional} correspondiente a la liberación de la versión \textbf{v1.0.0} del sistema \textbf{Yoliztli}. Tras la ejecución del Plan de Mantenimiento de Software y la aplicación de la Reingeniería de Procesos bajo el estándar \textbf{ISO/IEC/IEEE 14764:2014}, se procedió a realizar una auditoría integral de calidad compuesta por pruebas estáticas automatizadas con \textbf{SonarQube Community Edition v25.2.0} y pruebas dinámicas funcionales de caja negra.

El propósito fundamental de esta evaluación es verificar que el software reconstituido cumple rigurosamente con los criterios de calidad interna (ausencia de vulnerabilidades, cero bugs de confiabilidad y deuda técnica bajo control) y calidad externa (operatividad al 100\% en todas las interfaces de los roles Alumno, Docente y Administrador).

\subsection{Resumen del Entorno de Pruebas}
La auditoría final se llevó a cabo bajo las siguientes especificaciones técnicas de infraestructura:
\begin{itemize}
    \item \textbf{Servidor de Pruebas Local}: Fedora Linux 44 Workstation.
    \item \textbf{Motor de Base de Datos}: PostgreSQL 15.4 / Laravel Eloquent ORM.
    \item \textbf{Stack de Aplicación}: Laravel 10.x (PHP 8.2), Inertia.js 1.0, React.js 18.2, Vite 5.0.
    \item \textbf{Herramienta de Auditoría Estática}: SonarQube v25.2.0.
    \item \textbf{Herramientas de Linteo Pre-commit}: PHP-CS-Fixer (PSR-12) y ESLint 8.x.
\end{itemize}

\part{Manual de Usuario Operacional y Guía de Interfaces (v1.0.0)}

\section{Estructura de Roles y Navegación General}

La plataforma web **Yoliztli v1.0.0** está diseñada con una arquitectura basada en roles de usuario bien definidos:
\begin{enumerate}
    \item \textbf{Rol Estudiante (Alumno)}: Orientado a niños de educación básica para la lectura interactiva de cuentos y la resolución de minijuegos educativos.
    \item \textbf{Rol Docente (Profesor)}: Diseñado para monitorear el avance de grupos de alumnos, consultar reportes de lectura y gestionar evaluaciones.
    \item \textbf{Rol Administrador}: Encargado de la configuración global del sistema, la gestión de usuarios y la administración del catálogo de contenidos.
\end{enumerate}

\section{Conclusiones de Pruebas y Dictamen de Operatividad}

La evaluación integral realizada sobre la versión **v1.0.0** del sistema **Yoliztli** confirma el éxito rotundo del Plan de Mantenimiento y de la Reingeniería de Procesos implementada. Se certifica que:
\begin{enumerate}
    \item La calidad interna alcanzó la clasificación **Rating A** en SonarQube v25.2.0, erradicando los 67 bugs iniciales y remediando el 95.65\% de la deuda técnica.
    \item Las pruebas funcionales de caja negra alcanzaron una tasa de aprobación del **100\% (8/8 casos exitosos)**, comprobando la remediación de los filtros lógicos y de la persistencia de avance de estudiantes.
    \item Las 20 interfaces operacionales han sido verificadas y documentadas en este manual, garantizando la usabilidad completa para los roles Alumno, Docente y Administrador.
\end{enumerate}

Por lo anterior, se emite el **Dictamen de Liberación Aprobada para la Versión v1.0.0**.
